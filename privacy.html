プライバシーポリシー

制定日：2026年11月5日

1. このツールについて

claude-drive は、運営者本人が個人で使うためのツールです。利用者は運営者本人だけで、第三者の利用は想定していません。

2. 取得する情報

運営者本人が許可した範囲で、Google ドライブ内のファイルの一覧・内容・メタデータ（ファイル名、更新日時など）にアクセスします。

3. 利用目的

運営者本人の指示に基づき、AI アシスタント（Claude Code）が Google ドライブ内のファイルを閲覧・作成・編集するためだけに利用します。

4. 第三者への提供

取得した情報を販売したり、広告に利用したり、第三者に提供したりすることはありません。

5. 保存と管理

アクセスに必要な認証情報は、運営者本人が管理する実行環境の設定画面にのみ保存します。ソースコードや公開ページには記載しません。

6. 許可の取り消し

Google アカウントのサードパーティ アクセスの設定から、いつでもこのツールへの許可を取り消せます。取り消すと、ただちにアクセスできなくなります。

7. Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

8. お問い合わせ

GitHub リポジトリからご連絡ください。
